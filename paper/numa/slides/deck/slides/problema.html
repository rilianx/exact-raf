El problema

El producto deja una parte no lineal N que hay que encerrar

x̂ = x₀ + Σ xᵢεᵢ + xᵣ ξ
ŷ = y₀ + Σ yᵢεᵢ + yᵣ η

x̂ · ŷ = x₀y₀ + eᵀ(y₀x + x₀y) + N

N = x₀yᵣ η + y₀xᵣ ξ + (eᵀx + xᵣ ξ)(eᵀy + yᵣ η)

Los εᵢ son los símbolos de ruido y ξ, η los símbolos de error de cada factor; todos recorren [−1, 1].

Toda multiplicación conserva la parte lineal y encierra N en un intervalo [ℓ, h]:

c = (ℓ + h)/2,   zᵣ = (h − ℓ)/2

El mejor intervalo posible es el rango exacto de N. Eso es lo que calcula el Algoritmo 1.

N tiene dos partes: los términos x₀yᵣη + y₀xᵣξ, que acoplan el centro de un factor con el error del otro, y la parte cuadrática. Skalna y Hladík calculan exacto solo la parte cuadrática y acotan los otros dos términos por separado. Nosotros calculamos el rango de N completo.
