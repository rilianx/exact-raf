El ejemplo que seguiremos

Tres símbolos de ruido y error en ambos factores

Primer factor

x̂ = 1 + ε₁ + 2ε₂ + 2ε₃ + ξ

x₀ = 1,  x = (1, 2, 2),  xᵣ = 1

Segundo factor

ŷ = 1 + ε₂ − ε₃ + η

y₀ = 1,  y = (0, 1, −1),  yᵣ = 1

Parte lineal del producto

x₀y₀ + eᵀ(y₀x + x₀y) = 1 + ε₁ + 3ε₂ + ε₃

N = η + ξ + (ε₁ + 2ε₂ + 2ε₃ + ξ)(ε₂ − ε₃ + η)

y₀x + x₀y = (1, 2, 2) + (0, 1, −1) = (1, 3, 1), así que la parte lineal es 1 + ε₁ + 3ε₂ + ε₃. Los términos de acoplamiento son x₀yᵣη = η e y₀xᵣξ = ξ. Con tres símbolos de ruido, el zonotopo será un hexágono.
